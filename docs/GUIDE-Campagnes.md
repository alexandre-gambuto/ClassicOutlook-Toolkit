# Campagnes e-mail — guide (v12.1, 2026-11-16)

Tout se pilote depuis le classeur **Suivi des Campagnes.xlsm** (onglet de ruban « Campagnes »).
Outlook fait le travail en arrière-plan (brouillons, envoi cadencé, suivi des réponses) et reste utilisable.

## 1. Installation (une fois)

1. **Classeur** : le ranger dans `Classeurs\` du dossier de l'outil, à côté de `Suivi des mails.xlsm` (nom réglé par `CampaignWorkbookFilename` dans config.ini : ici `Suivi des Campagnes.xlsm`).
   Ouvrir le classeur, `Alt+F11` → `Insertion > Module`, le nommer `modCampaignBook` (fenêtre Propriétés, F4), coller `Suivi des Campagnes__modCampaignBook.txt` ; double-clic sur `ThisWorkbook`, coller `Suivi des Campagnes__ThisWorkbook.txt`. Enregistrer (format .xlsm). Fermer / rouvrir : l'onglet « Campagnes » est actif.
2. **config.ini** : reporter le bloc `config_ini_ADD_2026-10-24.txt` (section CAMPAGNES MAIL), **une seule fois** (si deux blocs existent, la dernière valeur de chaque clé gagne : supprimer le bloc en trop). Nom du classeur : `CampaignWorkbookFilename` (défaut `Suivi des Campagnes.xlsm`). Si le classeur est ailleurs que dans `Classeurs\` : `CampaignWorkbookPath=` chemin complet (ou `%TOOLKIT%\...`). Puis Maintenance > Configuration > Recharger.
3. **Outlook (VBE)** : `modMailCampaign` v12.1, qui s'appuie sur `modSmtp` v1.1, `modExcelBridge` v1.1, `modCommon` v1.4 et `modConfig` v3.16 ou plus récents, avec `modDefer` v1.17 et `ThisOutlookSession` v10.19 ou plus récents (remplacer le contenu de chaque module), puis `Débogage > Compiler`, puis `modDevTools.Reinit` (ou redémarrer Outlook).
4. **Bouton Outlook** : le menu Campagnes existant propose « 1 - Ouvrir le classeur ». Pour un bouton direct : Fichier > Options > Personnaliser le ruban (ou barre d'accès rapide) > Macros > `Projet.CampaignOpenWorkbook`. Le bouton « Aide » de l'onglet Emaileur (`Projet.CampaignHelp`) ouvre le classeur sur sa feuille Aide.
5. **Premier essai** : nouvelle campagne avec une seule ligne (votre propre adresse), Générer, Vérifier, Tester la ligne, puis Brouillons.

## 2. Parcours d'une campagne

| Étape | Bouton | Ce qui se passe |
|---|---|---|
| 1 | **Nouvelle campagne** | Un onglet par campagne (copie du modèle, mise en forme selon la charte des classeurs : en-tête bleu foncé, police Arial, volets figés sous la ligne 11). Nom + choix du **compte d'envoi** (une fois pour toute la campagne : compte du profil ou boîte partagée ; vide = compte par défaut). |
| 2 | Bloc du haut (lignes 1-9) | **Objet** (B5) et **Message** (B8) s'écrivent une seule fois, avec des champs `{{Prénom}}`, `{{Nom}}`, `{{Société}}`… = en-têtes de colonnes de la table (tout en-tête ajouté devient un champ). **Modèle** (.oft / .msg) facultatif : sans modèle, mail neuf avec la signature par défaut ; le texte est inséré au-dessus de la signature. **Pièces jointes** (bouton, séparateur `;`). **Dossier de classement** : code DV ou nom du dossier Outlook où ranger les envoyés (vide = déduit de l'objet) ; il doit désigner **un seul** dossier : « Vérifier » signale un dossier introuvable ou ambigu et bloque l'envoi. **Message de relance** (B9) pour l'étape 8. |
| 3 | **Importer un fichier** / **Nettoyer** | Fichier Excel ou CSV du marketing : la colonne e-mail est reconnue **par son contenu**, Prénom / Nom / Société par leur en-tête, les autres colonnes deviennent des champs `{{…}}` ; adresses déjà présentes ignorées. On peut aussi coller directement sous la ligne 11 (colonne Email obligatoire). Nettoyer : minuscules, `Nom <adresse>` → adresse, doublons et adresses douteuses dans la colonne **Contrôle** (suppression des doublons proposée). Avec Claude dans Excel : « Transforme cette liste en lignes pour ma campagne : colonnes Email, Prénom, Nom, Société ». |
| 4 | **Générer** | Remplit **Message (HTML)** et **Relance (HTML)** de chaque ligne (champs remplacés, texte → HTML Calibri 11, liens cliquables). Une ligne peut être retouchée à la main ensuite : la colonne est ce qui part réellement. Lignes déjà remplies : régénération sur demande. |
| 5 | **Vérifier** / **Tester la ligne** | Outlook contrôle chaque ligne sans statut : Contrôle = `OK` ou l'anomalie (adresse, objet vide, champ inconnu, modèle ou pièce jointe introuvable, doublon, compte introuvable, dossier de classement introuvable ou ambigu). Tester : **un** brouillon ouvert dans Outlook pour relecture. |
| 6 | **Brouillons** ou **Envoyer** | Brouillons : un par ligne, dans les Brouillons de la boîte d'envoi, à envoyer à la main (un ancien brouillon de la même ligne est remplacé, jamais doublé). Envoyer : envoi réel cadencé par Outlook (`CampaignStepSec`, pauses), récapitulatif puis mot de confirmation `ENVOYER`. Une anomalie de contrôle **bloque tout**. Avant chaque départ, Outlook écrit « Envoyé (en cours) le … » dans le Statut et le relit, puis « Envoyé le … » ; une ligne avec un Statut n'est jamais renvoyée. Seuls les brouillons des lignes envoyées sont supprimés. Une pièce jointe impossible à joindre au moment de l'envoi met la ligne en `ECHEC` avec la raison (le mail ne part pas incomplet). **Arrêter** interrompt. |
| 7 | (automatique) | Chaque mail envoyé est rangé par Outlook sans aucune fenêtre : Dossier de classement, sinon dossier du code DV de l'objet, sinon il reste dans Envoyés. La ligne reçoit l'identifiant du mail (brouillon envoyé à la main : statut « Envoyé manuellement le »). Une série d'envois à la main est enregistrée en une fois (10 s après le dernier). Compte d'envoi secondaire : ses Éléments envoyés sont relevés par Outlook après chaque envoi de campagne et à chaque « Actualiser les réponses ». |
| 8 | **Actualiser les réponses** / **Relancer** | Outlook relit le fil de chaque mail : **Réponses**, **Dernière réponse**, **Suivi** (Répondu / Sans réponse / Relancé / Non remis / Relance en brouillon). Réponses automatiques (absence, « bien reçu », y compris hors Exchange) et accusés de remise ou de lecture ignorés ; une vraie réponse l'emporte sur un rapport de non-remise. Un mail rangé ou archivé après l'envoi est retrouvé (Éléments envoyés, dossier de classement, dossier du code de l'objet) et la ligne mise à jour. Relancer (brouillons ou envoi) : « Répondre à tous » sur le mail d'origine avec le texte Relance (HTML), lignes **sélectionnées et visibles** (les lignes masquées par un filtre sont ignorées) ou toutes les lignes Sans réponse. **Ouvrir le mail** / **Ouvrir la réponse** : ligne active. |

La feuille **Campagnes** (bouton « Liste des campagnes ») résume chaque onglet : contacts, prêts, brouillons, envoyés, répondus, sans réponse, taux de réponse, dernière action. Double-clic = ouvrir. Compteurs aussi dans le ruban.

## 3. Bon à savoir

- **Pendant un envoi**, mieux vaut laisser Excel tranquille (aucune cellule en cours de saisie) : Outlook écrit les statuts dans le classeur ouvert et l'enregistre toutes les 10 lignes, à chaque pause, puis à la fin (`AfterOutlookCampaign`). Si Excel refuse d'écrire le statut, la même ligne est retentée 10 s plus tard ; après 6 refus de suite, l'envoi s'arrête avec un message. Un tri ou une ligne insérée pendant l'envoi ne fait plus partir un mail en double ni au mauvais contact : chaque ligne est retrouvée par son adresse et son objet, et une ligne dont le Statut n'est plus vide est sautée (le bilan de fin compte les lignes sautées). Brouillons, second envoi et relances sont refusés sur une feuille en cours d'envoi.
- **Statut « Envoyé (en cours) le … »** resté en place : Outlook n'a pas pu écrire « Envoyé le » après le départ, ou s'est arrêté entre les deux. La ligne est protégée comme envoyée. « Actualiser les réponses » la corrige si le mail est retrouvé ; si le Suivi indique « Mail introuvable », vérifier dans les Éléments envoyés et, si le mail n'est pas parti, effacer le Statut pour le renvoyer.
- **Réinitialiser les statuts** : rend envoyables les lignes non envoyées (brouillons, échecs). L'option « toutes les lignes » efface aussi le suivi des envois réels (double confirmation). Le bouton du même nom du ruban Outlook (onglet Emaileur) suit désormais la même règle : les lignes envoyées gardent leur statut. Avec un compte d'envoi secondaire, faire « Actualiser les réponses » avant de réinitialiser (les brouillons envoyés à la main sont alors enregistrés et ne redeviennent pas envoyables).
- **Nettoyer les brouillons** supprime dans Outlook les brouillons de cette campagne seulement.
- Les colonnes se reconnaissent **par leur nom exact** : déplaçables, complétables. Ne pas renommer Email, Cc, Cci, Objet, Message (HTML), Relance (HTML), Pièces jointes, Modèle, Contrôle, Statut, Suivi ni les colonnes techniques masquées (`_ConvID`, `_EntryID`, `_SentOn`, `_ReplyID`). Une colonne importée ou ajoutée dont le nom ressemble seulement à une colonne de pilotage (« Statut client », « Src Objet », « Logiciel ») reste un simple champ `{{…}}`. Le nom d'un onglet ne doit pas contenir `|`.
- Trier / filtrer par les flèches du filtre de la ligne 11 (le filtre couvre aussi les colonnes masquées : chaque ligne reste entière). Les lignes masquées par un filtre sont comptées partout (compteurs, Nettoyer, Générer) ; « Importer un fichier » réaffiche toutes les lignes avant d'écrire à la suite.
- Supprimer une campagne = supprimer son onglet. Dupliquer = nouvel onglet avec les mêmes paramètres, sans contacts.
- Mise en forme d'une feuille créée avant cette version (ou du modèle `_Modele`, rendu visible le temps de l'opération) : `Alt+F8` > `FormatCampaignSheet`, la feuille étant active.
- Les anciennes feuilles (en-têtes en ligne 1, 9 colonnes) restent utilisables par le menu Outlook (options 2 à 14) ; le suivi des réponses et les relances n'existent que dans le classeur des campagnes.
- Une seule instance d'Excel : Outlook cherche le classeur par son nom dans l'Excel ouvert (un chemin OneDrive peut apparaître en https, d'où la recherche par nom) ; classeur fermé → rouvert en silence depuis config.ini, enregistré puis refermé.
- Fermer le classeur juste après une action ne le fait plus réapparaître quelques minutes plus tard (l'effacement différé de la barre d'état est annulé à la fermeture).
- Icônes du ruban : un bouton sans icône (nom d'image non reconnu par cette version d'Office) reste fonctionnel.
